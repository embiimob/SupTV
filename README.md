# SupTV

Play the most recent Sup!? video by search string.

## Standalone player

Open `index.html` from the repository root in a browser to launch the fullscreen-capable SupTV player.
It auto-searches p2fk.io (default query: `supgalaxy`), starts playback immediately, and overlays live ticker/messages sourced from the same search results.
You can set the startup keyword with `?q=yourkeyword` (example: `index.html?q=supgalaxy`).
